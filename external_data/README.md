# External training/calibration imagery

The original research archive contains additional training and ESPDL-calibration images whose redistribution terms are not documented in the supplied package. They are therefore **not redistributed in this public-ready repository**.

The paper reports their experimental role and the final model artifacts are provided. To reproduce training from scratch, replace these images with the same source data only if you have redistribution/use rights, or with an equivalent licensed dataset using the class order `hammer=0`, `plier=1`.

The project-generated CoreS3 camera images used for domain adaptation and the frozen held-out validation split are included under `data/`.
